- 半開区間 [left, right)の時、二分探索が収束するためには、探索範囲にmidがなく、区間の幅が１つ以上縮むことが必要
bisect_right, bisect_leftの違い

例：重複ありの整数の配列numsからxを探す問題。なければxが入るインデックスを返す。numsは昇順に並んでいる
述語：nums[k] >= x
昇順なので、numsに対して、述語を適用した配列は「F,F,F,F,T,T,T」のようになる。

 1. bisect_left(nums, True, key=lamba num: num >= x)
以下bisect_leftの内部実装の模倣
求めているものは、「初めてTrueになる位置」
```python
def bisect_left(nums, x):
	def key(i):
		return nums[i] >= x
		
    l = 0
    r = len(nums)

    while l < r:
	    # 探索範囲は[l, r)
        mid = (l + r) // 2
        if not key(mid):
	        # l未満はFalse
            l = mid + 1 # midが探索範囲に含まれてはいけないので、mid + 1で更新する
        else:
	        # r以上はTrue
            r = mid
	# 収束する時、lは初めてTrueになる位置を表す
    return l
```

上記と同じ動作をbisect_rightで表すと、
2. bisect_right(nums, False, key=lambda num: num >= x)
※ bisect_right の内部条件は if x_val < key(mid)で r を動かすので、x_valに代入するのはFalseじゃないといけない。bisect_leftなら key(mid) < x_valで l を進める

以下内部実装の模倣
求めるものは、「最後のFalseの１つ後ろの位置 」, つまり初めてTrueになる位置
```python
def bisect_right(nums, x):
	def key(i):
		return nums[i] >= x
		
    l = 0
    r = len(nums)

    while l < r:
	    # 探索範囲は[l, r)
        mid = (l + r) // 2

        if key(mid): # False < key(mid) のときrを縮める
            r = mid
        else:
            l = mid + 1
	
    return l 
```

- bisect_right(nums, x)は？
	- bisect_right(nums, False, key=lambda n: n > x)と等価である

つまり、述語「nums[k] > x」が最後にFalseになる位置の一個後ろの位置を返す。
言い換えると、「xより大きい最初の要素の位置」= 「x以下の要素の個数」
```python
def bisect_right(nums, x):
	def key(i):
		return nums[i] > x
		
    l = 0
    r = len(nums)

    while l < r:
	    # 探索範囲は[l, r)
        mid = (l + r) // 2

        if not key(mid): # nums[mid] <= xに等しい
	        l = mid + 1
	    else:
		    r = mid
	
    return l 
```
